# FAROS — Multistrom Cluster of Satellites

Simulation code for the FAROS manuscript. Every figure and table in the paper is
produced by exactly one script listed below.

## Running

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
bash run_all.sh
```

## Script to figure and table mapping

| Output | Script |

path computation).

## Model

The routing graph is rebuilt after any topology change. Any change
to node positions invalidates the graph, and `shortest_path()` raises rather
than routing on a stale graph.

A link is admitted only if it satisfies all four of:

- **Earth occultation** — the straight segment between two satellites must not
  intersect the Earth. At 550 km this begins to bind above roughly 5,400 km.
- **Elevation mask** — 10° minimum from a ground station to a satellite.
- **Range limit** — 2,500 km for LEO-to-LEO inter-satellite links.
- **Link budget** — 10 dB C/N with 3 dB margin, which permits ranges to
  10,551 km under the stated parameters. The geometric limit therefore binds
  first, and no reported path is changed by the link-budget gate.

End-to-end delay is decomposed as

```
T = Σ over links ( d/c + L/R ) + Σ over relay nodes ( t_proc + t_switch + t_queue )
```

Per-node terms are charged only at intermediate nodes. The destination does not
relay and is not charged. Queueing is set to zero under an unloaded-network
assumption stated in the manuscript.

## Limitations

- Orbits are circular. No eccentricity, no J2 perturbation, no drag.
- No propulsion, delta-v, manoeuvre or station-keeping model. The constellation
  does not reconfigure; routing changes as satellites move along fixed orbits.
- No atmospheric, ionospheric or weather effects.
- No link capacity, queueing or traffic model.
- No power, mass, cost or collision-risk budget.
- Four link-budget parameters are adopted design values rather than measured.

An earlier version of this repository contained a coverage plot that computed
the slant range to the horizon as the radius of a flat disc rather than the
spherical cap, overstating coverage by 52% at 2,000 km. That plot has been
removed. Redundancy is now measured as the number of internally node-disjoint
paths between endpoints, in `figures/table3_orbital_planes.py`.
